# بذرة | Badra Innovation

منصة عربية لإدارة تحديات الابتكار والهاكاثون، من طرح التحدي إلى التصويت وتكوين الفرق والتحكيم وإعلان النتائج.

Arabic RTL innovation challenges, team participation, judging and results.

هذه نسخة عامة مستقلة لعرض الشيفرة والتطوير. لا تتضمن قاعدة بيانات التشغيل أو حساباتها أو ملفاتها أو تاريخ المستودع السابق.

## المزايا

- بطاقات التحديات ومساعد لصياغتها.
- التصويت والانضمام للفرق وصلاحيات المنظمين.
- بطاقات التحكيم وتقارير PDF وعرض النتائج.

## التشغيل المحلي

المتطلبات: Node.js 24 وnpm. البنية: TypeScript وReact وVinext/Vite، مع Cloudflare D1 للتخزين وR2 عند الحاجة.

```bash
npm install
npm run dev
```

افتح عنوان التطوير الذي يظهر في الطرفية (عادة http://localhost:5173). إعدادات الربط العامة موجودة في `.openai/hosting.json` دون معرف مشروع منشور. ملفات SQL في `drizzle/`؛ طبّقها على قاعدة بيانات بيئتك الجديدة قبل استخدام وظائف التخزين. التطوير يستخدم التخزين المحلي الذي توفره أدوات Cloudflare، ولا يتصل بقاعدة المشروع الأصلي.

DB وBUCKET، وخدمة Authentica لتسجيل الدخول. اضبط MANAGER_PHONES بقائمة أرقام المديرين الخاصة ببيئتك، مفصولة بفواصل. لا توجد حسابات مدير مضمّنة. إعدادات الحدث والتواريخ في lib/hackathon-event.ts.

```bash
npm run typecheck
npm run build
node --test scripts/test-employee-auth.mjs scripts/test-phone-admin.mjs scripts/test-challenge-publication.mjs scripts/test-jury-results.mjs
```

## إعداد بيئة مستقلة

راجع `.dev.vars.example` وانسخ المتغيرات المطلوبة إلى ملف `.dev.vars` محلي مستبعد من Git، أو إلى أسرار منصة الاستضافة. أنشئ موارد التخزين والحسابات الخاصة بك. بناء المشروع لا ينشئ هذه الموارد ولا ينشر موقعًا تلقائيًا.

تكامل تسجيل الدخول الخاص بالاستضافة الأصلية يحتاج بوابة تحقق موثوقة أو استبداله بمزود هوية في استضافتك. لا تثق بترويسات الهوية التي يرسلها العميل مباشرة، ولا تفعّل حساب التطوير الوهمي على الإنترنت. هذه النسخة ليست إعداد إنتاج جاهزًا بضغطة واحدة.
